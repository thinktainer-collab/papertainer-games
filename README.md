# Design sources

Source assets kept for upcoming games. This branch is not published:
GitHub Pages serves only `main`, so nothing here appears on games.papertainer.com.

| File | What it is | License |
|---|---|---|
| `kenney/kenney_cube-pets_1.0.zip` | Kenney Cube Pets, 3D animal models (FBX, GLB, OBJ) with previews | CC0 (public domain) |
| `kenney/Starter-Kit-Racing-main.zip` | Kenney Starter Kit Racing, a Godot racing project with models and audio | MIT, copyright (c) 2023 Kenney |

Source: https://kenney.nl and https://kenney.itch.io. Crediting Kenney is appreciated but not required.

To use a model in a game, unzip it locally and copy only the files the game needs into that game's folder on `main`.
