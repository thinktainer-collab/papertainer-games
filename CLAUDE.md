# Papertainer Games

Static browser games served by GitHub Pages at https://games.papertainer.com from `main` (no build step).

- `zombie-maze/`: 좀비 미로 탈출. Before changing it or adding an episode, read `docs/zombie-maze.md`: it holds the agreed rules, per-episode numbers, the checklist of things to confirm before building, the test procedure and open items. Update that document whenever an episode or a number changes.
- `ppung-rally/`: 뿡뿡 랠리, a separate game. Leave it alone unless asked.

Working agreements with the owner:

- For a new episode, ask about decisions that change the outcome before building; propose defaults for missing numbers.
- After automated playthroughs pass (all episodes, not only the new one), commit and push to `main` here directly.
- The portfolio site (`thinktainer-collab/papertainer`) goes through a pull request; the owner merges.
- Write user-facing text in Korean.
