# 좀비 미로 탈출 개발 노트

새 화를 만들거나 수정할 때 이 문서를 먼저 봅니다. 정해진 규칙, 화별 수치, 다음 작업 전에 확인할 것, 남은 일을 모아 둡니다.

## 작업 방식 (정해진 것)

| 항목 | 내용 |
|---|---|
| 요청 처리 | 새 화 요청을 받으면 결과가 크게 갈리는 부분만 먼저 질문하고, 답을 받은 뒤 구현합니다. 수치가 빠져 있으면 기본값을 제안해 함께 확인받습니다. |
| 게임즈 사이트 반영 | 자동 테스트를 통과하면 이 저장소 `main`에 바로 올립니다. 1~2분 뒤 games.papertainer.com에 반영됩니다. |
| 포트폴리오 사이트 반영 | `thinktainer-collab/papertainer`는 PR로 올리고, 머지는 사용자가 합니다. |
| 기기 | 모바일 터치가 기본(가로 화면 권장). PC 키보드와 마우스도 지원합니다. |
| 그래픽 | 이미지 파일 없이 코드로 그린 픽셀풍. 3D는 `game/three.module.min.js`(three.js 0.170.0, MIT). |
| 사이트 디자인 | 게임즈 홈은 papertainer.com과 같은 톤(검은 배경, Inter, 유리 느낌 메뉴바, BETA 라벨). 게임 화면 안은 게임 느낌을 유지합니다. |

## 공통 규칙

| 규칙 | 값 |
|---|---|
| 맨몸 체력 | 100 |
| 3화부터 나오는 더 큰 메카 | 탑승 중 체력 300, 레이저 데미지 3배, 빔이 굵음 |
| 체력 회복 | 피해를 입지 않는 동안 10초마다 10. 맞으면 10초를 처음부터 다시 셈 |
| 죽었을 때 | 그 구간 처음부터 다시 (화 전체가 아님) |
| 일반 좀비 | 닿으면 4 데미지, 권총 한 방 또는 레이저에 바로 죽음 |
| 권총 | 탄환 무한, 0.3초마다 한 발 |
| 옷장 | 숨으면 좀비가 찾지 못함 (1화 미로, 2화 추격전) |
| 메카 | 한 번 타면 그 화가 끝날 때까지 내리지 않음 |

## 화별 정리

### 1화
1. 미로(7×7칸, 매번 새로 생성)에서 열쇠 4개를 모아 출구 문을 연다.
2. 가장 센 좀비 등장. 권총은 통하지 않고, 메카에 타서 레이저로 쓰러뜨린다. 맞으면 25(메카 탑승 중 10).
3. 큰 문을 열면 공 던지는 좀비. 공 10 데미지, 레이저가 튕겨 나가서 메카 손으로 잡아 던져야 한다.
4. 새로 생긴 문으로 들어가면 끝.

### 2화
1. 레이저에 버티는 좀비. 메카 탑승 상태, 쓰러지기 직전 한 번 체력 1로 버팀.
2. 문을 열면 메카가 사라지고 추격전. 11×11칸 미로, 쫓아오는 좀비는 총으로 죽지 않음(잡히면 25), 옷장에 숨으면 약 9초간 놓침.
3. 미로를 빠져나오면 좀비 25마리, 옆의 메카에 타서 레이저로 처치.
4. 좀비 50마리와 조금 더 센 좀비를 처치하면 끝. 한 화면에 최대 25마리씩 나옴.

### 3화
1. 업그레이드된 공 좀비(공 20 데미지, 체력 60). 더 큰 메카에 타서 레이저로 처치.
2. 문을 열면 일반 좀비 15, 조금 더 센 좀비 3, 레이저에 버티는 좀비 1, 가장 센 좀비 1. 보스들 공격은 합쳐서 1초에 한 번만 들어감.
3. 다 없애면 문이 생기고, 열면 엄청 빠른 좀비(체력 50, 2초마다 15). 레이저로 0을 만들면 비틀거리고, 메카 손으로 땅에 꽂는다.
4. 2페이지(체력 118, 불가사리 15). 레이저로 처치하면 끝. 2페이지에서 죽으면 2페이지부터 다시.

### 4화
1. 더 큰 메카에 탄 채로 시작. 총 쏘는 좀비(체력 40, 1.5초마다 한 발 10 데미지)를 레이저로 처치.
2. 문을 열면 메모리 게임. 카드 16장(8쌍)을 AI와 번갈아 뒤집고, 짝을 더 많이 찾으면 승리. 맞히면 한 번 더. AI는 본 카드의 70%를 기억함. 지거나 비기면 메모리 게임만 다시.
3. 이기면 문이 열리고 사이보그 좀비(체력 150). 가까우면 주먹 20, 멀면 파이어 캐논 35, 죽을 때 폭발 30(8m 안). 레이저로 깎고, 가까이 오면 파란 버튼 "집게로 날리기"로 잡아 던짐(떨어질 때 50 데미지).
4. 사이보그를 쓰러뜨리면 문이 생기고, 열면 숨은 그림 찾기. 방 그림 한 장에서 바나나, 노트북, 스포츠카 장난감, 핸드폰, 모자를 1분 안에 찾음. 시간이 지나면 숨은 그림 찾기만 새 그림으로 다시. 다 찾으면 끝.

## 다음 화 요청 전에 정해 두면 좋은 것

새 화를 요청할 때 아래 항목이 들어 있으면 질문 없이 바로 만들 수 있습니다. 빠진 것은 작업 전에 질문하거나 기본값을 제안합니다.

| 항목 | 예시 |
|---|---|
| 시작 상태 | 맨몸인지, 메카에 탄 채인지, 어떤 메카인지 |
| 적마다 체력과 데미지 | "체력 50, 주먹 20, 2초마다 공격" |
| 쓰러뜨리는 방법 | 권총, 레이저, 메카 손(잡아 던지기, 땅에 꽂기), 집게 중 무엇이 통하는지 |
| 무엇이 통하지 않는지 | "총으로 안 죽음", "레이저가 튕김" 같은 제약 |
| 다음 구간으로 넘어가는 조건 | 다 없애면 문이 생김, 문을 열면 다음 적 등장 등 |
| 미니게임 규칙 | 이기는 조건, 제한시간, 실패하면 무엇을 다시 하는지 |
| 새로 생기는 조작 | 새 공격이나 버튼이 생기면 언제부터 쓰는지 |
| 끝나는 조건 | 마지막에 무엇을 하면 화가 끝나는지 |

## 화를 추가할 때 같이 고쳐야 하는 곳

- `zombie-maze/game/game.js`: 단계(`startStage`), 목표 문구(`OBJ`), 행동 버튼(`findAction`), 재시작 대상(재도전 버튼 처리), 시작 문구(`newGame`), 엔딩 문구.
- `zombie-maze/index.html`: 타이틀의 화 설명과 "N화 시작" 버튼, 새 화면(미니게임 등).
- 게임즈 홈 `index.html`: 카드의 `Episodes 1–N`과 설명 문구.
- `README.md`: 화 목록.
- 이 문서: 화별 정리와 수치.

## 테스트 방법

- 로컬 서버(`python3 -m http.server`)를 띄우고 Playwright로 휴대폰 가로 화면(844×390)에서 터치로 끝까지 자동 플레이합니다.
- 게임은 테스트용으로 `window.__zg`에 상태를 열어 둡니다(플레이어, 단계, 적, 메모리 게임, 숨은 그림 등).
- 새 화를 넣으면 1화부터 마지막 화까지 모두 다시 돌려 엔딩까지 가는지 확인합니다.
- 자동 테스트는 조준을 자동으로 하기 때문에, 손으로 할 때의 난이도는 실제 휴대폰에서 따로 확인해야 합니다.
- 이 작업 환경에서는 실제 사이트 주소와 외부 CDN에 접속할 수 없어서, 포트폴리오 사이트는 같은 버전의 Tailwind, GSAP, Font Awesome을 npm에서 받아 넣고 확인합니다.
